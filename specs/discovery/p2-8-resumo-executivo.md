# P2.8 — Resumo executivo

1. Vamos construir um aplicativo web de previsão do tempo para o público da empresa, com busca de cidades, clima atual, previsão de 5 dias e alternância entre Celsius e Fahrenheit.
2. O app será simples: sem login, sem cadastro e sem dados pessoais guardados nos nossos servidores, usando um serviço público de dados meteorológicos.
3. As escolhas principais já estão feitas: interface em português, temperatura em Celsius por padrão e previsão de hoje mais os 4 dias seguintes.
4. Antes de construir, precisamos confirmar se o serviço de dados pode ser usado comercialmente e definir o formato exato da previsão.
5. Com isso resolvido, o próximo passo é a especificação detalhada, que servirá de base para o planejamento e a implementação.
